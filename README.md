# 🪞 Muraayad Journal

**Muraayad Journal** waa web application casri ah oo loogu talagalay xusuus-qorka maalinlaha ah, fikirka gaarka ah, iyo kormeerka dareenka (mood tracking). Waxaa loo dhisay si gaar ah oo xogtaada ugu kaydinaysa browser-kaaga oo kaliya (privacy-first).

🔗 **Live Demo:** [https://muraayad.vercel.app](https://muraayad.vercel.app)

---

## 🚀 Features (Astaamaha App-ka)
- ✍️ **Qoris Cusub:** U qor xusuustaada si fudud oo xarago leh.
- 🎭 **Mood Tracker:** Dooro dareenkaaga maalinlaha ah (Degan, Dhiirran, Fikir, Nabad, Diyaar).
- 📖 **Xusuus-Qorradaada:** Eeg dhammaan qoraalladii aad horey u kaydisay.
- 📊 **Istaatistiko:** La soco tirada qoraallada iyo heerka dareenkaaga.
- 🔒 **Amaan & Gaar:** Xogtu waxay ku kaydsan tahay local storage.

---

## 🛠️ Tech Stack
- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
